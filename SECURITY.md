# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately through this repository's GitHub
Security Advisories feature. If private advisories are unavailable, contact the
repository maintainers privately before disclosing details publicly. Do not open a
public issue for an unpatched vulnerability.

Include the affected version or commit, the component involved, the impact, and
reproduction steps or a minimal proof of concept. Avoid sending real credentials,
private samples, or data belonging to other people.

The maintainers will acknowledge reports when practical and coordinate a fix and
disclosure timeline with the reporter. No response-time guarantee is implied.

## Supported versions

Security fixes are intended for the latest released version. Older releases may
not receive fixes; upgrade before reporting an issue as unresolved.
